    Documentation

    Keyboard shortcuts

    Enter sends, Shift+Enter newline, Ctrl+K search, Ctrl+, settings

    How to use

    Type a message and press Enter. The agent uses tools to help you. Click tool cards to expand details. Use Settings to configure your provider and API key.

    Supported providers

    Anthropic (Claude models) and [OI] (GPT models).

    File attachments

    Click the paperclip icon to attach files or images. The agent can see images directly and read text files.

    Tools, skills, MCP and plugins

    The Tools item in the sidebar opens the extensions hub. Paste a GitHub link and it installs whatever the folder contains: a skill (SKILL.md), a plugin (plugin.json) or MCP servers (mcp.json). MCP servers run as local child processes over stdio and their tools appear to the agent as mcp__server__tool. Everything is stored under .agent/ in this workspace.
